# Public preview v3

The private demo code is no longer required or used. Hosted AI is a limited anonymous preview. Per warm instance: 6 model calls/minute, 30/day, two concurrent requests; per client IP per instance: 3/minute and 12/day. Team mode reserves three calls. Limits reset across instances and are not a global protection. Optional shared database quota remains supported but is not provisioned. Provider quota and no paid fallback remain in place. Vercel firewall configuration could not be accessed. Monitor the provider account and disable CHINGU_AI_ENABLED followed by redeployment if abuse occurs. Do not present this as commercial production access. The legacy demo-code environment variable is unused and can be removed after the rollback window. Existing provider API-key requirements and consent are unchanged.
